# Volunteer User Guide - Gala Event Manager

## Getting Started

1. Open the app URL in your phone's browser (Chrome or Safari recommended)
2. Log in with the email and password provided by your event coordinator
3. You'll see the Dashboard with live event statistics

## Navigation

Use the menu icon (three lines) in the top-left to access:
- **Dashboard** - Live event overview
- **Guests** - Check-in and ticket sales
- **Impact Board** - Record pledges and donations
- **Auction** - View and manage auction items
- **Reports** - View summary data

## Guest Check-In

1. Go to **Guests**
2. Search for the guest by name using the search bar
3. Toggle the switch next to their name to check them in
4. The switch turns green when checked in

### Adding a Walk-In Guest

1. Tap **Add Guest** (top-right)
2. Enter their first and last name
3. Either select an existing party or create a new one
4. Check "Walk-in" box
5. Tap **Add Guest**

### Adding a Plus-One

1. Tap **Add Guest**
2. Enter the plus-one's name
3. Select the party of the person who brought them
4. Check "Plus One" box
5. Tap **Add Guest**

## Selling Raffle Tickets

1. Go to **Guests**
2. Find the guest
3. Tap the three-dot menu (⋯) on their row
4. Select **Sell Raffle Tickets**
5. Use +/- buttons to set quantity
6. Tap **Record Sale**

## Selling 50/50 Tickets

Same process as raffle tickets:
1. Tap the three-dot menu (⋯) on the guest row
2. Select **Sell 50/50 Tickets**
3. Set quantity and tap **Record Sale**

## Recording Pledges (Impact Board)

1. Go to **Impact Board**
2. Browse items by category (Shabbat, Holidays, etc.)
3. Tap an item to see details
4. Tap **Add Pledge**
5. Select the guest, enter the amount, and choose donation type
6. Tap **Add Pledge**

## Tips

- The app works offline! If WiFi drops, keep working - data syncs automatically when connection returns
- Look for the green "Online" badge in the header - if it shows "Offline", don't worry
- All your changes save automatically
- If something seems wrong, try refreshing the page (pull down on mobile)

## Need Help?

Contact your event coordinator or the system administrator.
